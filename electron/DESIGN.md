# HKUprint Studio 界面约定

本次范围：将外层 `Gcode view` 的离线切片器与三维走刀查看器整合为 Electron 桌面软件。实机控制台与固件继续由原项目维护。

采用 ui-ux-pro-max 的桌面交互、可读性和性能规则。数据库推荐的 Minimalism & Swiss Style 适合专业工具；搜索没有匹配到专门的切片工作台布局，因此布局按实际操作流程设计，不采用搜索中的宣传页模板。

- 默认浅色参数面板，深蓝顶栏和深色三维工作区；参数标签使用深色文字，输入框、按钮与面板有清晰边界。深色主题单独定义文字和控件配色。
- 主要操作使用绿色，三维预览中的亮绿色表示已完成走刀，蓝色表示待走路径，琥珀色虚线表示空移。图例与渲染器共用 CSS 配色变量，所有功能色都有文字说明。
- 中文使用本机微软雅黑 / Segoe UI，不依赖网络字体。基础字号 18px，输入值 18px，主要按钮 17px，辅助状态信息 12–14px。
- 左侧设置区域默认占可用宽度的 28%，最小 340px；支持拖动分隔线或顶部“布局”调整占比，并记住选择。预览区保留至少 680px，参数区最多占 50%，较小窗口自动限制范围；按分层填充、运动、曝光和工作区分组。
- 分隔线支持左右方向键、Shift 加大步幅、Home / End 到边界，双击或 Enter 恢复默认；顶部提供百分比输入框、滑块与恢复按钮，避免仅能拖动。调整时按动画帧合并布局更新，三维视口同步更新尺寸并保留观察角度。
- 参数采用紧凑的单行布局，名称在左、数值与单位在右；输入框高 34px，行间距 6px，分组上下内边距 10px。标签为 16px、输入值为 18px，参数错误在对应行下方显示。
- 层滑块位于预览左侧，当前层进度位于下方。两个滑块均支持键盘，并有按钮或单步操作作为替代。
- 文件导入、切片、导出明确显示处理中状态；参数变化使旧切片失效，重新切片后允许导出。
- 切片在 Python 子进程执行，G-code 在 Web Worker 解析。GPU 路径缓存按显示数量更新；静止时按需绘制。
- 模型预览最多 20,000 个三角面，实际切片保留原始网格。点击面可正视，视角可锁定为切片 Z。
- 支持深色主题、可见键盘焦点、快捷键与减少动画偏好。交付检查针对桌面窗口 1540×1000 与 1180×800，使用真实切片结果。
